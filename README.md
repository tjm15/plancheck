# PlanCheck

**Active development repository for the Local Plan work within [The Planner's Assistant](https://github.com/the-planners-assistant/main).**

The Planner's Assistant is an independent, open-source effort to develop connected computational tools and shared infrastructure for spatial planning. PlanCheck is part of that wider project, with an immediate focus on **English Local Plan preparation, analysis, examination and monitoring**.

The intended scope extends beyond document processing or procedural checklists. Areas under investigation include structured and versioned plans, spatial analysis and scenarios, policy and evidence relationships, consultation, examination support, and monitoring. Their implementations and interfaces are not yet settled.

## Repository roles

- **[tjm15/plancheck](https://github.com/tjm15/plancheck)** (this repository): the working development environment for experiments, research, code, evaluations and evolving designs. It is public, but material here may be provisional or incomplete.
- **[the-planners-assistant/main](https://github.com/the-planners-assistant/main)**: the broader project's organisation repository and curated public home. Selected, reviewed work can be transferred there as appropriate; the repositories are not automatically synchronised.

## Current status

**Early development / foundation stage.** The repository currently contains initial documentation, development conventions and a provisional website scaffold. It does **not** yet contain a functioning Local Plan application.

Plans, research hypotheses and proposed capabilities in this repository should not be mistaken for implemented or validated software. This is an independent project; no institutional affiliation or endorsement is implied.
